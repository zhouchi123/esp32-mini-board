# ESP32 最小系统板

用立创 EDA 从零画的一块 ESP32 最小系统板。目标是走通「原理图 → PCB → DRC → Gerber → 打样 → 焊接 → 点灯」这条完整链路，练的是硬件流程，也是后面写固件的载体。

## 板子参数

> 下列参数是从导出的 Gerber 包里**实测**出来的（板框、孔径、层数、文件数），不是估的。

| 项目 | 参数 |
|---|---|
| 层数 | 2 层 |
| 板框 | 100 × 100 mm |
| 元件占用区 | 约 32 × 14 mm |
| 安装孔 | 4 个 Φ6.14 mm（非金属化 NPTH） |
| 插件孔 | 6 个（Φ0.305 / Φ0.600 / Φ0.700 各 2 个） |
| 过孔 | 2 个 Φ0.305 mm |
| 主控 | ESP32 模组（位号 U1） |
| 板载 LED | LED1、LED2 |
| IO 引出 | 模块可用 IO 经排针引出（J1 等） |
| 设计工具 | 立创 EDA |
| Gerber 包 | 19 个文件（顶层/底层铜、丝印、阻焊、钢网、板框、PTH/NPTH 钻孔、IPC 网表等） |

## 我在这块板上想验证什么

1. 第一次画板，Gerber 导出这一关能不能过——打样厂不退回、不做错。
2. 板框和安装孔的尺寸是不是和设计一致（到货先用卡尺量）。
3. 焊接能不能自己完成（0603/0805 起步，先练手）。
4. 板子能不能跑起来：点灯 → 串口打印 → 接传感器。
